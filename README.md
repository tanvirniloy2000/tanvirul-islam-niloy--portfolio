# Tanvirul Islam Niloy | Portfolio

Personal portfolio website of Tanvirul Islam Niloy, Network Engineer & Researcher.

## Files

- `index.html` - page content
- `style.css` - styles and animations
- `script.js` - network background, scroll progress, reveal-on-scroll and active nav link
- `assets/` - profile photo and CV (PDF)

## Run locally

Open `index.html` in a browser. No build step is needed.

## Deploy

Push the repository to GitHub and enable GitHub Pages (Settings > Pages > Deploy from branch > `main` / root).
